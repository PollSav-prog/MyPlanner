# Мой планировщик (My Planner)

Настольное приложение для Windows 10 и 11: календарь, задачи, голосовой ввод, напоминания с «капелькой»,
мягкий двухнотный сигнал, погода и часы, интерфейс на русском, английском, немецком и французском.

Технологии: C#, WPF, .NET 10 (LTS), MVVM, SQLite, уведомления Windows (Toast).

> **Статус сборки.** Исходный код полностью написан, но в среде разработки не было ни .NET SDK, ни Windows,
> поэтому **программа не компилировалась и не запускалась**. Что проверено: корректность XAML/XML, баланс скобок,
> соответствие обработчиков и привязок, полнота переводов, логика разбора дат (перенесена на Python и проверена
> на 22 фразах). Первая сборка может показать ошибки компиляции — это нормально для кода, который ещё не
> собирался; их нужно исправить до выпуска. Подробности — в разделе «Что проверено и что нет».

## 1. Как получить установщик (без установки программ для разработки)

Установщик собирается автоматически на сервере GitHub — вам нужен только бесплатный аккаунт GitHub.

1. Зарегистрируйтесь на https://github.com и нажмите **New repository** (новый репозиторий), имя — например `MyPlanner`.
2. Загрузите в него всё содержимое этой папки (кнопка **uploading an existing file**; папку `.github` обязательно тоже).
3. Откройте вкладку **Actions** → **Build installer** → **Run workflow**.
4. Через 10–15 минут рабочий процесс завершится. Откройте его, внизу в разделе **Artifacts** скачайте
   **MyPlanner-Setup** и распакуйте zip — внутри `MyPlanner-Setup-1.0.0.exe`.
5. Если рядом красный крест: откройте шаг, который упал, и пришлите мне текст ошибки — я исправлю код.

### Альтернатива: собрать на своём компьютере с Windows

1. Установите **.NET SDK 10**: https://dotnet.microsoft.com/download
2. Установите **Inno Setup 6**: https://jrsoftware.org/isdl.php
3. Откройте PowerShell в папке проекта и выполните: `.\build.ps1`
4. Готовый установщик появится в `installer\Output\`.

## 2. Установка программы

1. Запустите `MyPlanner-Setup-1.0.0.exe` (права администратора не нужны).
2. Выберите язык установщика, нажимайте **Далее**. Можно поставить галочки:
   **ярлык на рабочем столе** и **запускать вместе с Windows**.
3. Нажмите **Установить**, затем **Готово**. Ярлыки появятся на рабочем столе (если выбрали) и в меню «Пуск».
4. Устанавливать .NET или другие библиотеки не нужно — всё входит в установщик.

При первом запуске программа предложит выбрать язык (по умолчанию подставится язык вашей Windows,
если он поддерживается).

## 3. Как пользоваться

**Окно.** Слева календарь, в центре «МОИ ПЛАНЫ» со списком задач выбранной даты, справа вертикальная панель
из девяти кнопок, внизу часы и погода. Размер окна меняется мышкой, размер и положение запоминаются.

**Календарь.** Красный круг — выбранная дата, точка под числом — на дате есть задачи, красная капелька в углу —
скоро событие (нажмите на неё, чтобы увидеть карточку). Кнопки `‹ ›` листают месяцы, `« »` — годы, «Сегодня» возвращает к текущей дате.

**Девять кнопок справа** (при наведении немного увеличиваются, подсвечиваются и показывают подсказку):

| Кнопка | Что делает |
|---|---|
| ➕ Добавить задачу | Форма новой задачи: название, описание, дата, время, приоритет, категория, напоминание, повторение |
| ✏️ Редактировать | Изменяет выбранную задачу (двойной щелчок по задаче делает то же самое) |
| ✔ Выполнено | Отмечает задачу выполненной и прекращает повторные сигналы |
| 🔁 Повторение | Каждый день / по дням недели / каждую неделю / месяц / год / через N дней |
| 🔊 Настройка звука | Звук, громкость, проверка сигнала, интервал повтора (по умолчанию 10 минут) |
| 🌙 Тихий режим | Отключает звук на 30 минут, 1/2/4 часа или до утра; уведомления остаются |
| ☁ Погода | Город (вводится вручную) и обновление погоды |
| 🕘 История | Выполненные, просроченные и удалённые задачи; можно восстановить |
| 🌐 Язык интерфейса | Меню языков, переключение сразу, без перезапуска |

Шестерёнка внизу справа открывает **Настройки** (11 разделов). Правая кнопка мыши по задаче — перенести на
сегодня, завтра или на неделю вперёд, удалить.

**Голосовое создание задачи.** Кнопка «Голосом»: выберите язык речи (он не зависит от языка интерфейса), нажмите
«Говорить» и скажите, например: «Завтра в три часа позвонить врачу». Программа покажет название, дату, время и повторение.
Если час неоднозначен («в три часа»), она спросит, что вы имели в виду, и предложит два варианта. Затем:
**Сохранить**, **Исправить** (откроется форма) или **Отмена**. Результат можно озвучить («Сохранить задачу?»).
Если микрофона нет, фразу можно набрать текстом — разбор работает так же.

Примеры, которые понимает разбор (русский, английский, немецкий, французский):
«В пятницу в десять утра сходить в магазин», «Через два дня в 14:30 записаться на приём»,
«Каждый понедельник в девять утра проверить почту», «Tomorrow at 3 pm call the doctor»,
«Morgen um 15 Uhr Arzt anrufen», «Demain à 15h appeler le médecin».

**Распознавание речи и интернет.** Если для языка в Windows установлен модуль распознавания речи, всё работает
локально. Если нет — используется онлайн-распознавание Windows (нужен интернет, и должна быть включена настройка
*Параметры → Конфиденциальность и защита → Речь*). Программа сообщает, какой режим используется. Чтобы работать без
интернета на немецком или французском, добавьте язык в *Параметры → Время и язык → Язык и регион* вместе с пакетом
распознавания речи. Озвучивание требует установленного в Windows голоса для нужного языка
(*Параметры → Время и язык → Речь*); если его нет, используется голос по умолчанию и программа об этом предупреждает.

**Капелька.** За 2 часа до события (можно 1, 1,5, 3 часа или свой интервал, на всю программу или для отдельной задачи)
возле даты в календаре появляется объёмная красная капелька и открывается карточка «У ВАС ЗАПЛАНИРОВАНО СОБЫТИЕ!».
Текст карточки можно изменить в *Настройках → Предупреждение-капелька*. Капелька исчезает после выполнения задачи и
передвигается при переносе. Если окно свёрнуто или скрыто в трей, приходит уведомление Windows.

**Напоминание в назначенное время.** Уведомление Windows + карточка + мягкий сигнал «тыдын — тыдын». Пока задача не
выполнена, сигнал повторяется (по умолчанию каждые 10 минут). Можно отложить на 10, 30 или 60 минут или отметить
выполненной. После перезагрузки Windows или выхода из сна состояние восстанавливается, а пропущенные события
показываются **одним** общим уведомлением, а не серией сигналов.

**Фоновая работа.** Кнопка закрытия окна сворачивает программу в трей (это можно отключить), напоминания продолжают
работать. Значок в трее: открыть, добавить задачу, тихий режим, **Выход** (полное закрытие программы).

**Данные** хранятся в `%APPDATA%\MyPlanner` (база `planner.db`, папка `Backups`, журнал `log.txt`).
Сохранение автоматическое. Резервная копия создаётся раз в сутки (в настройках можно изменить число копий,
создать копию вручную или восстановить из копии).

**Свои переводы.** Тексты интерфейса лежат в `Locales\*.json`. Чтобы добавить язык (например, `es-ES.json`),
скопируйте `ru-RU.json`, переведите значения и задайте поля `_native` (название языка на нём самом) и `_badge`
(две буквы). Файл можно положить в папку программы или в `%APPDATA%\MyPlanner\Locales`; перекомпилировать ничего не нужно.
Отсутствующие ключи автоматически берутся из русского файла.

## 4. Удаление

*Параметры Windows → Приложения → Установленные приложения → Мой планировщик → Удалить*
(или «Пуск → Мой планировщик → Удалить»). Автозапуск снимается автоматически. Ваши задачи останутся в
`%APPDATA%\MyPlanner` — удалите эту папку вручную, если данные больше не нужны.

## 6. Что проверено и что нет

**Проверено в среде разработки (без .NET):**
- XAML, csproj, sln — корректный XML; баланс скобок во всех 32 файлах C#;
- все обработчики событий и `x:Name` из XAML существуют в коде; привязки главного окна указывают на существующие свойства;
- все 224 ключа перевода, используемых в коде, есть во всех четырёх языках, подстановки `{0}` совпадают;
- разбор дат на русском, английском, немецком и французском — логика перенесена на Python (`tools/parser_check.py`),
  22 сценария проходят, включая все фразы из технического задания.

Запуск проверок: `python tools/static_check.py`, `python tools/parser_check.py`.

**НЕ проверено (требует Windows и компиляции):**
- компиляция C# и XAML; тесты xUnit (они запустятся автоматически в сборке на GitHub);
- реальная работа микрофона и распознавания речи, голосов синтеза, уведомлений Windows, трея, автозапуска;
- внешний вид (размеры, шрифты, тёмная тема, анимации при наведении) и звучание сигнала;
- работа после перезагрузки и выхода из сна (логика написана, на реальной системе не проверялась);
- установка и удаление через установщик на чистой Windows 10 и 11.

Ручной чек-лист для первой проверки:
1. Установка → ярлык в «Пуске» → запуск, выбор языка.
2. Добавить задачу через 3 минуты → при открытом окне и при свёрнутом пришло уведомление и прозвучал сигнал; повтор через 10 минут; «Выполнено» останавливает сигнал.
3. Задача через 2 часа → в календаре появилась капелька; карточка открывается по нажатию.
4. Голосом/текстом: «Завтра в три часа позвонить врачу» → подтверждение AM/PM → сохранение.
5. Смена языка на каждый из четырёх: нет русских надписей на английском; задачи остались как были.
6. Светлая/тёмная тема, перезапуск (язык, тема, окно и задачи сохранились), закрытие в трей, выход из меню трея.

## 7. Известные ограничения

- Повторяющаяся задача показывается в календаре только на ближайшей дате (будущие повторения не отмечаются заранее).
- Названия языков в меню показаны буквенными значками (RU, EN, DE, FR): Windows не отображает эмодзи-флаги.
- Погода берётся из Open-Meteo по названию города; при неоднозначном названии выбирается первое найденное совпадение.
- Windows показывает уведомления с кнопками только если уведомления не отключены в «Фокусировке внимания».
- Тема оформления использует экспериментальный API `ThemeMode` (Fluent) из .NET 9/10; если он изменится, потребуется правка `ThemeService.cs`.
